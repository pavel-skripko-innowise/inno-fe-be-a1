# Модуль 3. Управление пользователями

![Значок модуля «Управление пользователями»](../../../public/a1-module-badges/03-user-management.svg)

Здесь вы расширите API управления пользователями: изменение и удаление учётной записи, а также просмотр списка. Для повторных запросов и аудита опирайтесь на теорию из предыдущих модулей.

## Цели обучения

После модуля вы сможете:

- безопасно изменять данные пользователя с проверкой владельца и администратора;
- проектировать удаление с учётом связанных данных и повторных запросов;
- реализовать список пользователей с фильтрацией и постраничной выдачей;
- добавлять аудит и диагностические сведения к операциям управления.
