# Модуль 4. Трансформация файлов

![Значок модуля «Трансформация файлов»](../../../../public/a1-module-badges/04-file-transformation.svg)

Реализуйте преобразование текстовых файлов и изображений. Начните с общего контракта, затем добавьте форматы и ограничения для каждого типа данных.

## Цели обучения

После модуля вы сможете:

- описать общий контракт преобразования файла;
- выбирать библиотеку и проверять поддержку исходного и целевого форматов;
- безопасно обрабатывать ограничения размера, содержимого и параметров;
- выделять преобразование в отдельный компонент и диагностировать сбои.
